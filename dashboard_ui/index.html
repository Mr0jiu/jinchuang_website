说明

本表基于 3,254 个全量面签样本的固定阈值离线回放，仅用于解释阈值敏感性和准确率、召回率权衡。

该结果不代表生产模型采用固定阈值，也不等同于自适应阈值模型的真实运行指标。

策略建议

低阈值区间（0.90～0.93）：召回率较高，但命中数量和人工复核压力较大。

中阈值区间（0.94～0.96）：风险识别与复核量较为平衡。

推荐业务阈值（0.97）：在本次全量固定阈值回放中 F1 最高，适合作为当前业务高风险阈值；不代表模型评估最优阈值。

高阈值区间（0.98～0.99）：命中数量减少，但漏报风险上升。

同客户中多笔授信与重复使用区分度报告

-同客户业务类型判定准确率
-同客户业务类型综合 F1

背景

在贷款面签影像检测中，同一客户办理多笔授信或重复使用时，由于客户身份相同，不同贷款的面签图片往往具有很高的相似度；而面签原图被直接重复用于其他贷款时，图片同样会表现出极高相似度。仅依据"候选图片与原图的相似度"进行判断，容易把正常多笔授信误判为原图重复使用，增加风险误报和人工复核压力。

相似，不等于重复使用

同客户主要包含两类业务情形：

  • 多笔授信：客户身份相同，但每笔贷款均重新进行了真实面签，拍摄内容存在合理变化。
  • 重复使用：某笔贷款直接复用了历史面签图。

03

核心思路

先判断"是不是同一高相似组"，再判断"为什么相似"。

A

锁定原图与相似组

以历史面签原图为锚点，召回同组高相似候选。

B

确认同客户身份

通过客户主键确认关系，排除跨客户重复使用情形。

C

组内两两比较

同时计算候选—原图和候选—候选相似度，识别成对复用。

D

输出业务类别

近乎完全一致判为重复使用；同人但现场内容变化判为多笔授信。
